# Backlog Status Audit — August 2026

Every status claim in the previous `docs/BACKLOG.md` was re-checked against the code before the SortSwift parity rewrite. This file records the corrections and the evidence, so the changed statuses in the index are traceable.

Most claims held up. Five did not.

---

## Corrections applied

### 1. Card prices are discarded at formalize — V-001, V-002, A-005 downgraded

**Was:** V-001 Partial, V-002 Partial, A-005 Partial ("capital tied up per block").
**Now:** V-001 Partial (import-time fetch only), V-002 **—**, A-005 **—**.

This is a defect, not just a status error. Prices are fetched from Scryfall during CSV parse:

[`src/lib/manabox/csv-import.ts`](../../src/lib/manabox/csv-import.ts) lines 175–182:

```ts
    return {
      ...row,
      scryfallId: card.id,
      name: row.name || card.name,
      setCode: card.set.toLowerCase(),
      imageUri: getCardImageUri(card) ?? null,
      priceUsd: getCardPriceUsd(card, row.finish),
    };
```

But `StagingCard` in [`prisma/schema.prisma`](../../prisma/schema.prisma) has no `priceUsd` column, so the fetched value is dropped when staging rows are persisted. Formalize then hardcodes null onto every card line:

[`src/lib/staging/formalize.ts`](../../src/lib/staging/formalize.ts) lines 103–106:

```ts
                quantity: 1,
                position: card.position ?? index + 1,
                priceUsd: null,
                imageUri: null,
```

**Consequence:** every block created through the primary intake path has `priceUsd = null` on all card lines. The dashboard "estimated value", the analytics "capital in stale blocks" figure, and the block detail value total all sum to **$0** for real inventory. Only backup-restored data carries prices.

Tracked as a defect: **V-005** in [`epic-07-pricing.md`](epic-07-pricing.md). It is a **Must** and blocks Epic 13 (`PRC-`), since an autopricing engine needs a cost and market column that actually persists.

### 2. B-006 block tags/tiers — Partial → Schema

**Was:** Partial. **Now:** Schema.

`BlockTier` exists as an enum and is displayed read-only on block detail:

[`src/app/blocks/[blockId]/page.tsx`](../../src/app/blocks/[blockId]/page.tsx) line 215:

```tsx
<dd className="text-zinc-200">{BLOCK_TIER_LABELS[block.tier]}</dd>
```

But no code path ever sets it to anything other than the default. Formalize hardcodes `tier: "GENERAL"` ([`src/lib/staging/formalize.ts:87`](../../src/lib/staging/formalize.ts)), and there is no UI to change it. A user cannot tag a block, so this is database-and-label only.

### 3. P-002 route optimization — Partial → Schema

**Was:** Partial. **Now:** Schema.

`pickSortKey` and `findBlockForPick` exist in [`src/lib/blocks.ts`](../../src/lib/blocks.ts), but `/pick` is a stub page with no behaviour and nothing calls the routing helpers from a user-reachable path. Helper functions with no caller are Schema, per the status key.

### 4. B-009 and O-005 describe the same capability

**Was:** B-009 "Audit log for block changes" Done, O-005 "Full change history" Partial.

Both are satisfied by the same `InventoryEvent` platform delivered under **B-013**. Keeping two statuses invites drift. **B-009** remains the canonical story and is **Done**; **O-005** is retired with a *Superseded by B-013* line in [`epic-08-operations.md`](epic-08-operations.md).

### 5. B-001 create block — Partial, reason clarified

**Was:** Partial, "via staging formalize; manual create is I-001".

Status is right but the reason was misleading: block creation is not partially built, it is fully built through one path and deliberately absent from another. Restated as **Done (staging path)** with **I-001** carrying the manual-create slice, so the index does not imply unfinished work where a product decision was made.

## Capabilities absent entirely

Confirmed by search across `src/`, for the parity matrix baseline:

Authentication, users, roles, and any actor identity (`InventoryEvent.actor` is nullable and never written); multi-game support of any kind; any pricing rule engine; any outbound marketplace API call; POS; buylist; shipping; consignment; general CSV export beyond the per-block Mana Pool listing and the JSON backup.

`BlockChannel` (`MANAPOOL`, `EBAY`, `TCGPLAYER`) is a label on a block. It performs no sync.
