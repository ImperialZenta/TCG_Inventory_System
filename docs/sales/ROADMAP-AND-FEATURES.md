## Page 1 — Features

### Available today — Intake & staging

ManaBox CSV upload · staging review · block breakdown · position-indexed intake · formalize to shelves/bins · undo whole import · 5,000+ cards/import · pending queue & upload logs

### Available today — Bulk inventory

Block IDs · shelf → bin → block · lifecycle (open/sealed/picked/liquidated) · move & bulk seal · activity audit log

### Available today — Catalog & picking

Scryfall enrichment · Mana Pool orders · location-sorted pick lists · pick/short/substitute · hold & quarantine · counter pick · TCGplayer pullsheet · pick history

### Available today — Analytics & platform

Aging dashboard & stale list · search by block ID · Mana Pool CSV export · JSON backup/restore · self-hosted Docker

*Dollar valuation pending pricing persistence.*

### In progress

Persist market prices · search by card name · global qty by card · bulk block transfer · secure webhooks

### Two inventory modes

| | Bulk / chaos | Sorted stock (planned) |
|--|--------------|------------------------|
| Best for | Trade-ins, bulk | Listed singles |
| Address | Block + position | Shelf / SKU |
| Online singles | No | Yes — live sync |
