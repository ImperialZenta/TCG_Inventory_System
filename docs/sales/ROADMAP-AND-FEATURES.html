Product features & roadmap · August 2026

Available today — Intake & staging

  • ManaBox (and compatible) CSV upload after counter scanning
  • Staging review before inventory goes live
  • Automatic block breakdown by target card count
  • Position-indexed intake — every card keeps pile order
  • Formalize into numbered blocks with shelf/bin assignment
  • Undo an entire import in one action
  • Large imports validated at 5,000+ cards
  • Pending queue, upload logs, status badges

Available today — Bulk inventory

  • Block IDs (MTG-0001, …) with shelf → bin → block hierarchy
  • Lifecycle: open, sealed, picked, liquidated
  • Move blocks; seal individually or in bulk
  • Capacity hints; block notes
  • Full activity / audit log

Available today — Catalog & picking

  • Scryfall enrichment; condition, foil, language
  • Mana Pool order import
  • Location-sorted pick lists; picked / short / substitute
  • Position renumber after picks; counter pick from one block
  • Hold pick lists; quarantine blocks for repair
  • TCGplayer pullsheet upload; pick history & metrics
  • Correction workflow for bad scans

Available today — Analytics & platform

  • Block age dashboard, aging buckets, stale block list
  • Search by block ID
  • Mana Pool listing CSV export per block
  • JSON backup and full restore
  • Self-hosted Docker + PostgreSQL — your data, no commission

Dollar-based valuation reports await pricing persistence (in progress).

In progress

  • Market prices saved on inventory (valuation currently $0)
  • Search by card name across all blocks
  • Global quantity by card
  • Bulk block transfer between locations
  • Secure webhooks and scheduled job authentication
